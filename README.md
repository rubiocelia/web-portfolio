# web-portfolio

Portfolio de Celia Rubio, diseñadora web y desarrolladora frontend.

Hecho con HTML, CSS y JavaScript, sin frameworks.

## Estructura

```
index.html          Portada
proyectos/          Una página de análisis por proyecto
css/
  variables.css     Colores, tipografía, espaciado, modo oscuro y tonos de proyecto
  base.css          Reset, tipografía base, layout y accesibilidad
  components.css    Piezas comunes a todas las páginas: header, botones, footer
  home.css          Secciones de la portada
  proyecto.css      Plantilla de las páginas de proyecto
js/
  main.js           Header, modo oscuro, tono por proyecto y menú activo
assets/img/         Imágenes
```

## Verlo en local

Con la extensión Live Server de VS Code: clic derecho en `index.html` → "Open with Live Server".
