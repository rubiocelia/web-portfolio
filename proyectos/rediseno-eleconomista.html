Trabajo profesional en elEconomista

Una estructura propia para elEconomista.es: más libertad para diseñar las noticias

Un cambio de estructura en la web del periódico para mejorar cómo se ven las noticias: Bootstrap deja paso a una rejilla propia, programada desde cero con CSS Grid, que da más libertad para diseñar y carga menos.

Punto de partida
Toda la web dependía de Bootstrap: teníamos que ajustarnos a las clases que ofrecía, y cada noticia tenía que encajar en sus columnas fijas.
Resultado
Una estructura flexible que nos da libertad de diseño: cada noticia se adapta a la relevancia que tiene en cada momento.

El punto de partida

Toda la maquetación de la web dependía de Bootstrap. Funcionaba, pero cargaba muchas reglas que no se usaban y obligaba a pensar cada bloque dentro de las columnas del framework.

Una rejilla propia

Bootstrap deja paso a una rejilla propia con CSS Grid: 12 columnas en escritorio, 6 en tablet y 1 en móvil. Las rejillas se anidan, así que la portada, cada bloque de noticias y el contenido de cada noticia usan el mismo sistema y quedan alineados.

El motivo es la libertad de diseño: en un periódico, cada noticia puede necesitar un tamaño distinto según su relevancia, y con las clases de Bootstrap teníamos que ajustarnos a lo que ofrecía el framework. Ahora diseñamos lo que necesitamos y la web ya no carga ninguna hoja de estilos de Bootstrap.

En móvil todo pasa a una columna, salvo la cabecera y la barra lateral, que mantienen su propia rejilla.

Colores y tipografías en variables

Los colores y las tipografías viven en variables CSS. Cada sección del periódico tiene su color, y cambiarlo es cambiar un solo valor.

  • elEconomista#ff6600
  • Hover#e05500
  • Informalia#809a17
  • Evasión#dd3333
  • Eventos#4477ee
  • Texto#242424

Los titulares usan Georgia y el texto Roboto, con alternativas de sistema. Son fuentes que ya están en la mayoría de dispositivos, así que la página no espera a descargar tipografías antes de mostrarse.

Pensado para las Core Web Vitals

Google mide la experiencia de una web con tres métricas, las Core Web Vitals. Cada decisión de la nueva estructura ayuda a alguna de ellas:

Métrica Qué mide Qué decisiones la mejoran
LCP Cuánto tarda en verse el contenido principal Sin la hoja de estilos de Bootstrap, menos CSS que descargar; tipografías de sistema que no hay que esperar; las imágenes de más abajo se cargan solo al acercarse a la pantalla
CLS Si la página da saltos mientras carga Cada bloque tiene su sitio reservado en la rejilla, y las imágenes llevan su tamaño, así que nada empuja al resto al aparecer
INP Cuánto tarda en responder al tocar o hacer clic La maquetación es CSS puro: no hace falta JavaScript para colocar ni redimensionar bloques, y el navegador tiene menos trabajo
